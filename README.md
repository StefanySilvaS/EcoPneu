# 📝 To-Do List

Projeto de lista de tarefas desenvolvido com **HTML, CSS e JavaScript**, com foco em praticar lógica de programação e manipulação do DOM.

Permite organizar tarefas do dia a dia de forma simples e intuitiva.

---

## Funcionalidades

- Adicionar tarefas
- Adicionar tarefa pressionando **Enter**
- Marcar tarefas como concluídas
- Limpar tarefas concluídas
- Contador de tarefas
- Layout responsivo (funciona no celular)

---

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
